# Design system

产品使用原创的“证据脊柱”视觉：暖米白纸张底色、细边界和一条陶土橙证据线贯穿答案，不复制任何品牌 Logo、插图、文案或完整布局。页面优先呈现答案和可追溯证据，技术事件放在运行时间线上。

色彩 Tokens：`#F7F4ED` 背景、`#FCFAF6` 表面、`#2D2926` 文字、`#746E66` 次要文字、`#E2DDD3` 边界、`#C76645` 强调、`#55725B` 已验证、`#9A6A35` 部分验证、`#A5534D` 风险。

标题使用 Newsreader（不可用时 Georgia），正文使用 Plus Jakarta Sans（不可用时系统无衬线），代码/数值使用系统等宽或浏览器默认。圆角保持 6–13px，阴影仅用于输入面板；动效控制在 150–220ms，并尊重 `prefers-reduced-motion`。

移动端把侧边栏变为抽屉，不允许横向滚动；所有按钮、表单字段和状态均提供键盘焦点与文本说明。
