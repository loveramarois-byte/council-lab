# 脱敏诊断包

Council 只会在用户点击“设置 → 诊断与支持 → 导出诊断包”后生成 ZIP。文件留在用户选择的下载位置，不会自动上传或发送。

归档固定包含两个文件：

- `README.txt`：生成时间、用途和隐私边界。
- `diagnostics.json`：应用版本、Python/平台/架构、SQLite `quick_check`、数据库大小和记录数量、匿名 Provider 就绪摘要、席位运行参数，以及 Council 标准日志文件的大小和修改时间。

诊断包明确排除：

- 用户问题、模型回答、资料正文和历史审议内容；
- API Key、Authorization、Cookie、手机配对令牌和系统凭据；
- 日志正文、模型名、主机名、用户名、IP 地址和文件系统路径。

实现采用白名单字段，而不是导出后再用关键词替换。后端回归测试把唯一敏感字符串写入数据库、日志和配置，再检查整个 ZIP 中不存在这些字符串；CI 和 Release 都执行该隐私测试。

诊断包仍会包含版本、平台、架构、Provider 类型和记录数量等运行元数据。发送给维护者前应先解压检查；无法接受这些元数据时，不要发送。
