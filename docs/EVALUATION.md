# Evaluation

评测入口保留在 `/evaluations`，当前没有真实评测数据，所有指标显示为 `—`。新增评测问题时，应给出问题类型、参考答案或可执行测试、来源和风险等级；比较引导、圆桌、深挖模式时记录事实准确率、引用准确率、未经证实主张数量、关键遗漏覆盖率、人类偏好、延迟、Token、可计算成本和 Provider 失败率。

没有真实 API 凭据时只运行 Mock 流程和 Provider 集成测试，不能把 Mock 结果写成真实模型表现。工作流回归必须验证四席顺序、最终确认点、第五次总结、用户补充传播、五席配置快照、真实运行边界、确定性上下文裁剪、SQLite checkpoint 数量、启动恢复条件，以及删除 Run 时的 checkpoint 清理。

当前版本不执行外部事实核验，因此 `FinalDecision` 只能将结论标记为未核验，并区分明确表态产生的分歧。未来若接入外部工具，评测必须保存工具、来源时间、限制和可复现步骤，不能仅依赖模型自述。
