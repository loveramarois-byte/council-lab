# Council Lab 100 项本机演练报告

## 口径

本轮在隔离的本地前后端进程中执行 100 个独立 Chromium 用户场景，不调用付费真实模型，也不把自动化演练描述成模型质量 Benchmark。测试端口为 `3200/8101`，没有修改或停止用户正在运行的 `Council.app`。

## 场景组成

| 场景 | 数量 | 结果 |
|---|---:|---:|
| 现有产品主路径、手机、无障碍、恢复、幂等、更新与高风险流程 | 52 | 52 通过 |
| 历法、闰日、时辰边界与本地快照 | 12 | 12 通过 |
| 医疗、法律、投资、合规、生产操作危险意图 | 12 | 12 通过 |
| 必填、同意、快捷键与字段长度门禁 | 8 | 8 通过 |
| 通用/传统模式控制与数据隔离 | 8 | 8 通过 |
| 320、344、360、375、390、414、430、768 像素结果页 | 8 | 8 通过 |

## 发现与修复

首次对抗演练确认 9 类动作型表达可以绕过原来的高风险关键词：开药处方、起诉、签合同、抄底数字资产、期货仓位、报税、生产上线、故障回滚和英文 production deploy。

修复位于中央传统文化意图判定函数，而不是 UI 或单句黑名单。规则同时增加非行动性反例，避免把传统契约、医药史、税制史、农业生产节律等研究问题全部误拦截。修复后 12 个危险用例全部返回失败关闭，未创建持久 Run。

首次基线还出现两个 `403`，根因是隔离后端没有配置测试前端端口。补充 `COUNCIL_FRONTEND_PORT=3200` 后 52/52 通过。这是测试环境配置问题，且证明浏览器来源边界按设计拒绝未知端口，不计为产品缺陷。

## 最终验证

- Chromium E2E：100 passed
- 后端：354 passed（覆盖率门槛 72%）
- 前端单元测试：11 passed
- 发布一致性与请求边界专项：58 passed
- TypeScript：通过
- Next.js production build：通过
- Python compileall 与 `git diff --check`：通过
- `npm audit --omit=dev`：0 vulnerabilities

## 客观限制

- 本轮没有进行 100 次付费真实模型调用，不能据此判断传统解释质量、跨模型一致性、成本或延迟。
- 关键词与动作模式只能降低已知误用风险，不能证明自然语言分类对所有表达都完备；服务端输出隔离、无决策资产和用户确认点仍是必要的纵深防御。
- 本地排盘结果可复现不代表传统解释具有科学有效性或预测准确率。
