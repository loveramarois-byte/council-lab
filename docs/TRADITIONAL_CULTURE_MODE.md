# 传统文化联合研判模式

## 定位

该模式把“可重复的本地排盘”和“不可当作科学事实的传统解释”分开。它适合个人研究传统历法、八字与紫微体系的规则、差异和叙事边界，不是预测准确率产品，也不是高风险决策工具。

## 计算与四席

- `lunar-javascript@1.7.7` 计算公农历、四柱、柱五行和天干十神。
- `iztro@2.5.8` 计算紫微基础盘与十二宫。
- 校历席核对输入、时间与计算口径。
- 辨典席区分明确体系、规则来源和个人推断。
- 参派席比较八字、紫微及不同流派可能的一致和冲突。
- 证伪席寻找巴纳姆效应、确认偏误、事后归因与不可证伪表达。

`bazi-skill` 提供了有价值的解释与交互组织参考，但不是本模式中的计算引擎。`ziwei-doushu` 依赖 `iztro` 与 `lunar-javascript`，共享底层结果不能算独立交叉验证。本项目不打包其大型数据集，也不调用第三方命理服务。

## 参考典籍索引

新建传统文化 Run 时可以选择研究方向索引。当前索引包括：

- 《穷通宝典》（常见作《穷通宝鉴》）：论日主调候
- 《三命通会》：论格局神煞
- 《滴天髓》：论五行旺衰
- 《渊海子平》：论十神六亲
- 《千里命稿》：论命例实证
- 《协纪辨方书》：论择日神煞
- 《果老星宗》：论星命合参
- 《子平真诠》：论用神格局
- 《神峰通考》：论命理辨误
- 《周易》：论卦象与象数
- 《紫微斗数全书》：论星曜与宫位
- 《星平会海》：论星命合参与格局

这些条目是版本化的书名和主题标签，不是内置全文、自动引文或独立计算引擎。模型上下文与导出报告会明确标记“仅为研究方向，不代表已读取或引用原文”；需要原文核对时，用户应自行提供可核验版本。

## 输入口径

- 只接受 1900-01-01 至今天的公历日期。
- 记录出生时间及“准确 / 约数”精度。
- 性别只作为现有排盘引擎参数。
- 出生地可选，只在本地记录且不发送给模型；不收集姓名。
- 固定使用 `Asia/Shanghai` 民用时。
- 当前不做真太阳时、经纬度或夏令时历史校正。

临界日期、时辰交界和真太阳时敏感案例可能因口径不同产生另一张盘。结果页和导出会明确记录本次口径、引擎版本和快照 SHA-256。

## 隐私

出生资料属于敏感个人资料。排盘先在浏览器本地完成，不调用第三方命理 API。只有用户在新建页明确勾选同意后，排盘字段与必要出生参数才会作为本次 Run 的冻结上下文发送给已配置的四个讨论席与总结席；可选出生地只保存在本地。数据继续遵守 Council 的本地数据库、Provider 和导出边界。

## 强制边界

- 固定使用“先独立初答”与专用模板。
- 禁止启用高风险控制或自动总结。
- 禁止注入历史决策记忆或选择专业决策输出契约。
- 医疗、用药、法律、投资、合规和生产操作意图在 API 与 Orchestrator 两层拒绝。
- 动作型表达同样拒绝，包括开药/停药、起诉/签约、交易与仓位、报税/监管放行、生产上线/回滚及相应英文表达；非行动性的历史和文化研究仍可使用。
- 传统解释不会进入 `verified_claims`、DecisionBrief、决策回访或长期记忆候选。
- 最终答案必须区分计算快照、传统解释、流派分歧、反证与限制、非约束性观察。

代码和测试通过只能证明软件按上述规则运行，不能证明命理解释或预测具有科学有效性。
