# Mac App Store 元数据（简体中文）

## 名称

Council

## 副标题

多视角决策支持工作台

## 宣传文本

让四种互相制衡的视角共同拆解问题、挑战假设、构造方案并核验结论。默认本地保存，AI Provider 由您决定。

## 描述

Council 是一款本地优先的多视角决策支持工具，适合需要认真比较方案、记录分歧与追踪依据的复杂问题。

每次审议由四个职责清晰的席位依次参与：拆解问题、寻找反例、构造可行方案、观察遗漏，再由汇总席形成可追溯的决策摘要。您可以查看讨论过程、关键假设、证据状态、风险提示和最终结论，而不是只得到一段无法复盘的回答。

核心能力：

- 四席讨论与独立汇总
- 决策摘要、历史记录和对比复盘
- 证据、分歧、置信度与未决事项提示
- 医疗、法律和金融问题的增强风险控制
- 内置 Mock 演示，无需账号或 API 密钥
- 可选配置第三方 AI Provider
- 本地优先存储与应用沙盒保护

Council 的专业领域输出仅用于信息整理和决策支持，不构成诊断、处方、法律意见、投资建议或其他专业服务，也不能替代有资质专业人士。Council 不验证用户填写的专业身份或资质。

第三方 AI Provider 完全可选。只有在您主动配置并选择 Provider 时，完成请求所需的提示词、上下文和资料才会发送给该 Provider，并受其隐私政策约束。

按 App Store Connect 问卷如实填写。应用不包含成人内容、赌博或社交功能；专业领域风险提示不应被表述为医疗服务。

## URL（提交前必须替换）

- 支持 URL：填写公开可访问、包含联系方法的 HTTPS 页面
- 营销 URL：可选
- 隐私政策 URL：将 `docs/app-store/privacy-policy.md` 发布到公开 HTTPS 页面后填写

## App 隐私问卷建议

- Tracking：否
- User Content / Other User Content：用于 App Functionality
- Linked to User：Council 没有账号系统；应依据实际 Provider 集成和 Apple 问卷定义复核后填写
- Analytics / Advertising：否
- Diagnostics：本机生成，除非用户主动发送给支持方，否则不由开发者收集

最终答案必须与实际构建、隐私清单、隐私政策和所有第三方 Provider 的行为保持一致。
